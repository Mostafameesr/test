# Telegram Ultra Video Compression

Automated Telegram video download, transcoding into multiple H.264, HEVC, AV1 and VP9 resolutions, followed by separate LZMA2 7z Ultra archives.

Run the **Telegram Video - Ultra Encode + 7z** workflow from the **Actions** tab. Default video: https://t.me/DB_Fans/29.

See [setup and usage](README-TELEGRAM-ULTRA.md) for detailed instructions and optional Telegram authentication secrets.
